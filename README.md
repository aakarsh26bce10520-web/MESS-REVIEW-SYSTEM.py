# 🍽️ Mess Feedback System

## Overview

The **Mess Feedback System** is a simple, menu-driven Python command-line application that lets students or residents of a hostel/mess view the daily food menu, submit feedback (a 1–5 rating plus a comment) for each meal, and generate a report showing average ratings and all comments per meal. It's a lightweight beginner-friendly project demonstrating modular Python programming, dictionaries, and basic CLI interaction.

## Features

- **View Mess Menu** — Displays the menu for Breakfast, Lunch, Snacks, and Dinner.
- **Give Feedback** — Submit a rating (1–5) and a comment for any meal of the day.
- **View Feedback Report** — See the average rating for each meal along with all submitted comments.
- **Simple CLI Menu** — Easy-to-use, number-based navigation with input validation on ratings.
- **Modular Code** — Menu display, feedback collection, and reporting are separated into individual modules.

## Technologies / Tools Used

- **Language:** Python 3
- **Core Concepts:** Dictionaries, Lists, Functions, Modules, CLI I/O
- **Libraries:** None — uses only Python's built-in features (no external dependencies)
- **Tools:** Any code editor / IDE (VS Code, PyCharm, etc.), Git & GitHub for version control
